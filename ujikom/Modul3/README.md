## Panduan Integrasi Git & GitHub
1. Inisialisasi repositori Git:
   ```bash
   git init
   ```
2. Tambahkan dan lakukan commit:
   ```bash
   git add .
   git commit -m "ujikom modul 3"
   ```
3. Hubungkan ke repositori remote GitHub dan dorong perubahan:
   ```bash
   git remote add origin https://github.com/aalwisyahri/portofolio-junior-web.git
   git push
   ```
